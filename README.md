# Zorgon IDE

**A lightweight Python IDE built for learning, experimentation, and self-improvement.**

Zorgon IDE is a simple desktop code editor developed using Python and Tkinter. It started as a casual personal project to explore GUI development, code editing features, and process management while building something useful along the way.

This project is a work in progress, and I intend to keep improving it over time, with the long-term goal of supporting multiple programming languages.

## Features

- **Code Editor** — Write and edit Python scripts in a dedicated editor.
- **Syntax Highlighting** — Color-coded Python keywords, built-ins, strings, comments, numbers, and function or class definitions.
- **Line Numbers** — Easily navigate and keep track of code lines.
- **File Management** — Create, open, save, and save Python files.
- **Execution Console** — Run Python scripts and view standard output and error messages.
- **Interactive Input** — Provide input to running programs through the console.
- **Execution Control** — Start and stop program execution.
- **Editing Tools** — Undo, redo, cut, copy, paste, and select all.
- **Automatic Indentation** — Automatically indent new lines and increase indentation after a colon.
- **Customizable Editor** — Adjust font size and toggle line numbers or the console.
- **Keyboard Shortcuts** — Use familiar shortcuts for common editing and execution tasks.
- **Dark Theme** — A dark interface designed for comfortable coding.
- **Basic Execution Status** — View whether a script is running, finished, failed, or terminated.

## Built With

- **Python** — Core application logic and script execution.
- **Tkinter** — Desktop graphical user interface.
- **Python Standard Library** — File handling, subprocess management, threading, queues, and other utilities.

## Execution

Run the application:

```bash
python main.py
```

Depending on your system, you may need to use `python3 main.py` instead.

No third-party Python packages are currently required by the application.

## ⌨️ Keyboard Shortcuts

| Shortcut           | Action             |
| ------------------ | ------------------ |
| `Ctrl + N`         | New file           |
| `Ctrl + O`         | Open file          |
| `Ctrl + S`         | Save file          |
| `Ctrl + Shift + S` | Save as            |
| `Ctrl + Z`         | Undo               |
| `Ctrl + Y`         | Redo               |
| `Ctrl + A`         | Select all         |
| `Ctrl + C`         | Copy               |
| `Ctrl + X`         | Cut                |
| `Ctrl + V`         | Paste              |
| `F5`               | Run Python file    |
| `Shift + F5`       | Stop execution     |
| `Ctrl + +`         | Increase font size |
| `Ctrl + -`         | Decrease font size |

## Current Limitations

- This is an experimental personal project and may contain bugs or limitations.
- Advanced IDE capabilities such as debugging, code completion, and package management are not currently implemented.
